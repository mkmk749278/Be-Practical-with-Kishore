2. **Replay of the session logs:** the nine Claude sessions that worked on `Creator` from 05 to 18 NOV were read in
   full (186 log pages), and every file operation in them was replayed in time order onto the base: file writes and
   edits, `cat >` heredocs, `sed -i`, and the small Python edit scripts the sessions used for rule and handoff changes.
   The 05 NOV reorganisation was redone from the `Built-on-Bharat` backup (`lib/remotion`, `scripts/blender`, extra
   scripts, `remotion-render.yml`, `blender-render.yml`), and the pre-05 NOV films were moved out of git as the owner
   decided that day ("code in git, media in Drive"; they are in the bundle).
3. **Drive:** small text files from each later film's Drive folder are in `projects/<slug>/recovered-from-drive/`
   (VO block text, captions, YouTube metadata, footage logs, VO locks). Full listing of the films' Drive media:
   `docs/recovery/drive_films_index.txt`. For Matsya 6000, whose narration text was not in any log, the locked VO
   (SHA-256 matches its `lock.json`) was transcribed: `recovered-from-drive/vo/transcript_from_locked_vo.tsv`
